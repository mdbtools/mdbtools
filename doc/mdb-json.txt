NAME
  mdb-json - Export data in an MDB database table to JSON.

SYNOPSIS
  mdb-json [-D fmt] [-T fmt] [-U] [-A] [--limit rows] database table
  mdb-json -h|--help
  mdb-json --version

DESCRIPTION
  mdb-json is a utility program distributed with MDB Tools. 

  It produces JSON output for the given table. Such output is suitable for parsing in a variety of languages.

  By default each row is written as a JSON object on its own line (JSON Lines). With --array the rows are instead wrapped in a single JSON array.

OPTIONS
  -D, --date-format fmt     Set the date format used for columns formatted as Short Date (see strftime(3) for details).
  -T, --datetime-format fmt Set the date/time format used for other date columns (see strftime(3) for details).
  -U, --no-unprintable      Change unprintable characters to spaces (otherwise escaped as \\u00XX).
  --limit rows              Stop after exporting rows rows. Default is to export the whole table.
  -A, --array               Output one JSON array containing all the rows instead of one object per line. An empty table produces [].
  --version                 Print the mdbtools version and exit.

NOTES 

ENVIRONMENT
  MDB_JET3_CHARSET    Defines the charset of the input JET3 (access 97) file. Default is CP1252. See iconv(1).
  MDBICONV            Defines the output charset to use for the SQL file. Default is UTF-8. mdbtools must have been compiled with iconv.
  MDBOPTS             Colon-separated list of options:
                      * debug_like
                      * debug_write
                      * debug_usage
                      * debug_ole
                      * debug_row
                      * debug_props
                      * debug_all is a shortcut for all debug_* options
                      * no_memo (deprecated; has no effect)
                      * use_index (experimental; requires libmswstr)
